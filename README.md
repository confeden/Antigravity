# Antigravity в России без VPN и смены региона аккаунта Google

Программа для Windows, Linux и macOS (Apple Silicon): позволяет аккаунту Google любой страны (в том числе России) пользоваться Antigravity 2.0, Antigravity IDE, Antigravity CLI и расширением Antigravity для VS Code. Настройка делается один раз для компьютера, после этого можно входить с любыми аккаунтами. После обновления Antigravity анлокер патчит его заново сам.

Видеоинструкция: https://youtu.be/aybWT_7wtqA

## Установка

1. Скачайте последнюю версию в [Releases](https://github.com/confeden/Antigravity/releases) и установите Antigravity с [официального сайта](https://antigravity.google/download).
2. Запустите анлокер **от имени администратора** (правой кнопкой по файлу). Без прав администратора ставится только патч клиента, а служба, снимающая ошибку 400 «User location is not supported», нет.
3. Введите бесплатный ключ из закреплённых сообщений группы [t.me/nova_txt](https://t.me/nova_txt/69864). Ключ свой для каждой версии: после обновления анлокера нужен новый.
4. Нажмите **«Включить всё»** (Antigravity закроется на пару секунд).
5. Запустите Antigravity, войдите в аккаунт и напишите что-нибудь в чат. Карточка вверху окна станет зелёной: **«Работает. Модель ответила …»**.

Любой переключатель можно выключить: выключение и есть откат этой части.

Свой DNS: в «Настройках для опытных» можно вписать свой DNS-сервер (IPv4). Он участвует в пуле наравне с остальными, и каждый его ответ сверяется с эталонным, поэтому сервер без подмены ничего не ломает.

## С VPN и без

Ничего настраивать не нужно, ни с VPN, ни с чужим DNS. Соединения Antigravity с двумя серверами Google идут через службу на вашем компьютере, и VPN их не перехватывает. Путь выбирается по тому, **на каком реально ответила модель**, а не по скорости; путь, на котором пришла ошибка, откладывается.

## Терминальная версия (TUI)

Для сервера по SSH или если окно не открывается. Команда сама берёт последнюю версию.

```bash
curl -fsSL https://raw.githubusercontent.com/confeden/Antigravity/main/tui.sh | sh
```

В PowerShell от администратора:

```powershell
irm https://raw.githubusercontent.com/confeden/Antigravity/main/tui.ps1 | iex
```

Вставьте ключ и нажмите Enter. Стрелки: выбор, Пробел: включить или выключить, `q`: выход.

## Linux

Распакуйте архив и запустите `launch.sh` (двойной клик или `bash launch.sh`). `sudo` не нужен: если Antigravity стоит в папке root (`/opt`), анлокер сам запросит пароль через pkexec только для записи патча.

## macOS

Нужен Mac на Apple Silicon (M1 и новее) и macOS 13 или новее. Распакуйте `AG_<версия>_macos.tar.gz` и запустите `Запустить.command`. Если macOS не даёт открыть файл, нажмите на него правой кнопкой → «Открыть» или выполните в Терминале `xattr -dr com.apple.quarantine` и путь к распакованной папке. Если патч не записывается, разрешите Терминалу «Управление приложениями» в «Настройки → Конфиденциальность и безопасность».

## Если не работает

Смотрите карточку вверху окна: она пишет, что мешает (антивирус, файрвол, другая программа) и что делать. Не помогло — напишите об этом в группу.

## Что меняется в системе

Всё точечно и откатывается переключателями в окне.

1. **Language Server / CLI** (`language_server.exe`, `agy.exe`): две строки одинаковой длины: `ineligible` → `inexigible` (снимает региональное ограничение) и `https_proxy` → `AG_LS_PROXY`. Размер файла не меняется.
2. **Локальный прокси и служба** (`%ProgramData%\AGUnlocker`, порт `127.0.0.1:53129`): на него указывает только `AG_LS_PROXY`. Системный `HTTPS_PROXY` не трогается, `git` и браузеры работают как раньше. TLS не расшифровывается, сертификаты не ставятся.
3. **DNS-правила (NRPT)** только для `cloudcode-pa.googleapis.com`, `daily-cloudcode-pa.googleapis.com` и `aicode.googleapis.com` (голосовые запросы). Остальной DNS, включая вход в аккаунт, идёт обычным путём.
4. **Приоритет IPv4** над IPv6, только если у вас нет глобального IPv6; снимается при откате.

Gemini CLI не поддерживается: Google закрыл в нём вход для личных аккаунтов, и обойти это на стороне клиента нельзя.

В открытом коде нет списка встроенных выходов и серверной части маршрута «Прокси из группы» (чтобы чужие серверы не перегружались); без них программа собирается и работает на остальных маршрутах.
